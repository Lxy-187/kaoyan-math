# 考研数学一 · 复习知识库

按知识树组织的个人题型库：解题方法、例题、以及**你自己的思路记录**。

## 怎么用

**看**：双击 `index.html` 就能打开，不需要任何环境或联网（KaTeX 已经放在本地了）。

**更新**：不在网页上编辑，而是**直接跟 Claude 说**。比如：

> 我在复习导数应用的证明题，这是我跟 AI 的对话，帮我整理进去：<粘贴对话>

Claude 会自己判断该放到哪个学科、哪一章、哪个专题，然后更新对应文件。你刷新页面就能看到。

也可以直接指定位置：

> 整理到 `calculus/derivative-app/inequality`

## 页面上的约定

内容块用颜色区分来源，扫一眼就知道在看什么：

| 颜色 | 含义 |
|---|---|
| 🔵 蓝 | 定理、公式、必背结论 |
| 🟣 紫 | 方法论、解题套路 |
| 🟢 绿 | **你自己的思路和顿悟** |
| 🔴 红 | 易错点、会丢分的地方 |
| 🟡 琥珀 | 例题卡 |

例题的**思路 / 解答 / 点评默认折叠**，方便先自己想再对答案。

## 快捷键

| 键 | 作用 |
|---|---|
| `/` | 聚焦搜索框 |
| `e` | 展开 / 折叠本页所有解答 |
| `[` `]` | 上一篇 / 下一篇 |
| 顶栏 `◐` | 明暗主题（跟随系统 → 浅色 → 深色） |

## 结构

```
content/manifest.js    知识树：3 个学科 / 25 章 / 92 个专题
content/<学科>/<章>/    各专题的内容文件
assets/                样式与脚本
vendor/katex/          本地公式渲染
```

侧栏里灰色斜体的专题 = 还没有内容，跟 Claude 说一声就会填上。

## 本地起服务（可选）
